# 第四章  面向多工况动力电池的工况调制与控制条件响应一致性异常检测

> 本章为论文方法章节草稿。公式采用普通文本公式块并按 `(4-x)` 编号，不依赖 LaTeX 渲染。模型结构已经实现；清华 EV Brand3 五折复验仍在运行，因此本章只陈述方法、假设与实验设计，不预写性能结论。

## 4.1 研究背景

动力电池异常检测面对的核心困难之一，是“工况变化”与“故障变化”在观测空间中可能具有相似表现。充电电流增大、SOC 进入不同区间或充电阶段发生切换时，总电压、单体电压极值和温度极值均可能产生显著变化。这些变化在物理上可能完全正常，但对一个只学习全局平均模式的异常检测器而言，却容易形成较大的预测或重构残差。另一方面，某些故障并不会使响应量立即偏离全局数值范围，而是首先表现为“在当前电流和 SOC 条件下，电压或温度响应不再合理”。

这两个问题分别对应两类不同的信息需求：

1. 模型需要知道当前窗口属于何种统计运行模式，从而以工况相关的方式解释主干特征；
2. 模型需要判断实际电—热响应是否符合给定控制轨迹下的正常响应规律。

为此，本文以 MTAD-GAT 为共同骨干，提出两条相互平行的增强路线：

- C3：全窗口数据驱动工况调制模型；
- C4：无响应泄漏的控制条件响应一致性模型。

C3 与 C4 不在同一个模型中联合开启。C3 作用于共享主干内部，属于表示层条件化；C4 与主干解耦，属于评分层异构证据融合。保持两条路线独立，有利于明确性能变化来自工况调制还是控制—响应一致性残差。

## 4.2 符号定义与基础检测骨干

### 4.2.1 数据与变量划分

设第 `n` 个长度为 `T` 的多变量窗口为 `X^(n)`，特征维数为 `D`：

```text
X^(n) = [x_1^(n), x_2^(n), ..., x_T^(n)] ∈ R^(T×D)             (4-1)
```

清华 EV 数据中 `D=7`，通道顺序为：

```text
x_t = [V_pack,t, I_t, SOC_t, V_max,t, V_min,t, T_max,t, T_min,t]   (4-2)
```

根据变量在电池系统中的作用，将其划分为控制量与响应量：

```text
C_t = [I_t, SOC_t]                                                (4-3)

Y_t = [V_pack,t, V_max,t, V_min,t, T_max,t, T_min,t]             (4-4)
```

其中，`C_t ∈ R^2` 表示外加工况与荷电状态，`Y_t ∈ R^5` 表示需要检测的电—热响应。该划分只用于 C4；C3 的工况编码器读取完整的七通道窗口。

主要符号如下。

| 符号 | 含义 | 清华 EV 中的维度 |
|---|---|---:|
| `X` | 完整输入窗口 | `T×7` |
| `C` | 电流/SOC 控制窗口 | `T×2` |
| `Y` | 五通道响应窗口 | `T×5` |
| `d` | C3 窗口统计描述向量 | `28` |
| `z_reg` | C3 工况嵌入 | `8` |
| `H` | 三路主干融合表示 | `T×21` |
| `z_ctrl` | C4 控制轨迹潜变量 | `16` |
| `U` | C4 控制派生序列 | `T×5` |
| `S_base` | MTAD-GAT 基础异常分数 | 标量/窗口 |
| `S_con` | C4 控制—响应一致性分数 | 标量/窗口 |

### 4.2.2 MTAD-GAT 共享骨干

本文保持原始 MTAD-GAT 的基本信息流不变。输入窗口首先经过一维卷积，提取局部变化模式：

```text
H_conv = ReLU(Conv1D(X))                                         (4-5)
```

随后，Feature-GAT 在变量维度建模跨通道依赖。对特征节点 `i` 与 `j`，注意力兼容度及归一化权重可抽象表示为：

```text
e_ij = LeakyReLU(a_f^T [W_f h_i || W_f h_j])                     (4-6)

A_ij^F = exp(e_ij) / Σ_k exp(e_ik)                               (4-7)

H_feat,i = σ(Σ_j A_ij^F W_f h_j)                                 (4-8)
```

Temporal-GAT 在时间节点间建立相似的注意力关系：

```text
A_ts^T = softmax_s(e_ts^T)                                       (4-9)

H_temp,t = σ(Σ_s A_ts^T W_t h_s)                                 (4-10)
```

卷积分支、特征注意力分支和时间注意力分支在最后一维拼接：

```text
H = Concat(H_conv, H_feat, H_temp) ∈ R^(T×3D)                    (4-11)
```

对清华 EV，`3D=21`。融合表示经 GRU 编码为窗口级隐藏状态 `h_end`，再分别送入下一点预测头和窗口重构头：

```text
h_end = GRU(H)                                                    (4-12)

y_hat_(T+1) = F_forecast(h_end)                                  (4-13)

X_hat = F_reconstruction(h_end)                                  (4-14)
```

代码中的基础训练损失不是普通 MSE 之和，而是预测 MSE 与重构 MSE 分别开平方后的 RMSE 之和：

```text
L_fore = sqrt( mean((y_(T+1) - y_hat_(T+1))^2) )                 (4-15)

L_rec  = sqrt( mean((X - X_hat)^2) )                             (4-16)

L_base = L_fore + L_rec                                          (4-17)
```

推理时，对参与报警的响应维度 `r`，计算下一点预测绝对误差和窗口末点重构绝对误差：

```text
e_pred,r = |y_(T+1),r - y_hat_(T+1),r|                           (4-18)

e_rec,r  = |x_T,r - x_hat_T,r|                                  (4-19)
```

基础窗口分数为各响应维度两类误差的加权均值：

```text
S_base = mean_r( w_pred,r·e_pred,r + w_rec,r·e_rec,r )           (4-20)
```

固定融合模式下 `w_pred=1`，`w_rec=γ`；质量感知模式下，权重由正常校准误差的相对 MAD 稳定性确定。

## 4.3 C3：全窗口数据驱动工况调制模型

### 4.3.1 方法动机与建模假设

C3 的基本假设是：相同的主干特征在不同统计工况下不应被完全相同地解释。设 `z_reg` 表示当前窗口的运行模式，则主干表示的条件分布应写为 `p(H | z_reg)`，而不是忽略工况后统一使用 `p(H)`。C3 并不显式划分离散簇，也不使用人工工况标签；它学习的是连续低维工况流形。

清华 EV 的最终版 C3 使用完整七通道窗口。这样做的目的，是让工况表示覆盖电流、SOC、电压和温度共同形成的整体数据模式。该设计与 C4 有严格区别：C3 不负责从控制量生成响应，因此允许看到响应；C4 负责预测响应，因此预测路径禁止读取响应。

最终 C3 由三个模块组成：

1. 全窗口统计描述与工况编码；
2. 融合层 FiLM 条件调制；
3. 工况语义辅助约束。

### 4.3.2 模块一：全窗口统计描述构造

对完整窗口的第 `c` 个通道 `X_:,c`，计算四个边际统计量。

第一，窗口均值刻画变量的工作水平：

```text
μ_c = (1/T) Σ_(t=1)^T x_t,c                                     (4-21)
```

第二，窗口标准差刻画局部波动幅度：

```text
σ_c = sqrt( (1/T) Σ_(t=1)^T (x_t,c - μ_c)^2 )                   (4-22)
```

第三，首尾差刻画窗口尺度上的净变化方向：

```text
δ_c = x_T,c - x_1,c                                              (4-23)
```

第四，平均绝对一阶差分刻画局部变化速度：

```text
ν_c = (1/(T-1)) Σ_(t=2)^T |x_t,c - x_(t-1),c|                   (4-24)
```

由此得到单通道描述向量：

```text
d_c = [μ_c, σ_c, δ_c, ν_c] ∈ R^4                               (4-25)
```

七个通道按固定语义顺序拼接：

```text
d = Concat(d_1, d_2, ..., d_7) ∈ R^28                           (4-26)
```

这四类统计量分别对应“水平—波动—全局趋势—局部动态”。与直接将完整序列输入高容量编码器相比，描述量构造具有三个作用：

- 限制工况分支容量，降低其复制原始窗口的能力；
- 提供明确可解释的自监督目标；
- 保留与充电模式识别直接相关的一阶统计和变化信息。

该编码器不显式计算通道对相关性。跨通道关系仍由 Feature-GAT 负责，因此工况分支与主干关系学习的功能边界保持清晰。

### 4.3.3 模块一：低维工况嵌入学习

统计描述向量经两层 MLP 压缩为连续工况嵌入：

```text
h_d = GELU(W_d1 d + b_d1)                                       (4-27)

z_reg = W_d2 h_d + b_d2,     z_reg ∈ R^8                        (4-28)
```

`z_reg` 不是预定义类别的 one-hot 编码，也不直接等价于“充电簇”“静置簇”等标签。更准确的学术表述是：`z_reg` 是由窗口边际统计量参数化的连续工况表示。只有在后续可视化或聚类分析中观察到自然分组时，才能将其解释为统计工况簇。

对于 MSL/SMAP，现有路线保持不变。匿名上下文通道先由共享通道 MLP 编码，再进行 mean/max 置换不变池化。清华 EV 则保留七个通道的固定物理顺序，不做通道池化。

### 4.3.4 模块二：融合层 FiLM 参数生成

FiLM 条件器将 `z_reg` 线性映射为两组长度为 `3D` 的参数：

```text
[a_γ, a_β] = W_F z_reg + b_F                                   (4-29)

γ = tanh(a_γ),     β = tanh(a_β)                                (4-30)
```

`tanh` 将调制参数限制在 `[-1,1]`。设调制幅度为 `s`，在当前实验中 `s=0.1`，则对每个时间步共享同一组窗口级调制参数：

```text
H_tilde,t,k = H_t,k·(1 + s·γ_k) + s·β_k                         (4-31)
```

其中 `t=1,...,T`，`k=1,...,3D`。式 `(4-31)` 包含两种作用：

- 乘性项 `(1+sγ)` 改变不同融合特征的相对敏感度；
- 加性项 `sβ` 对工况相关的表示基线进行平移。

例如，若某一融合维度主要响应温度快速上升，而该变化在某种大电流工况下属于正常现象，FiLM 可以适当降低该维度对后续 GRU 的贡献。需要注意，这只是表示层调制机制的直观解释，不能在没有归因实验时把某一具体维度直接解释为温度或电压语义。

### 4.3.5 恒等初始化与稳定性机制

FiLM 投影层的权重和偏置均初始化为零：

```text
W_F = 0, b_F = 0  ⇒  γ = 0, β = 0                              (4-32)

H_tilde = H                                                     (4-33)
```

因此，加入 C3 后模型在第一个训练步之前严格等价于原 MTAD-GAT。恒等初始化避免随机 FiLM 参数在训练初期破坏主干表示，也使 C3 与 baseline 的差异能够归因于后续学习到的工况调制。

此外，`s=0.1` 对最大调制幅度进行限制。即使 `γ` 或 `β` 饱和，单次条件化也不会任意重写主干表示。

### 4.3.6 模块三：工况语义重建头

仅依赖 `L_base` 训练时，工况编码器可能学习一个对预测有利但缺乏稳定语义的捷径。为约束 `z_reg`，从其重建原始统计描述：

```text
d_hat = W_aux z_reg + b_aux                                    (4-34)
```

采用 Smooth-L1 损失。对单个误差 `q=d_hat_j-d_j`：

```text
                 { 0.5 q^2,         |q| < 1
SmoothL1(q) =    {
                 { |q| - 0.5,       |q| ≥ 1                    (4-35)
```

批量辅助损失为：

```text
L_state = mean_j SmoothL1(d_hat_j - d_j)                        (4-36)
```

Smooth-L1 在小误差区域保持二次可导，在大误差区域转为线性增长，可减弱极端工况窗口对辅助任务的支配。

### 4.3.7 C3 联合训练目标

C3 总损失为：

```text
L_C3 = L_fore + L_rec + λ_state·L_state                         (4-37)
```

正式 `film_true` 实验使用：

```text
λ_state = 0.05                                                  (4-38)
```

`film_no_aux` 令 `λ_state=0`，用于判断收益来自 FiLM 本身还是语义约束；`baseline` 关闭整个工况分支。

### 4.3.8 推理阶段与异常评分

C3 推理时仍使用式 `(4-18)` 至 `(4-20)` 的 MTAD-GAT 预测/重构异常分数。工况分支不输出独立异常分数，其作用体现在调制后的预测值和重构值中：

```text
X → d → z_reg → FiLM(H) → GRU → {y_hat, X_hat} → S_base,C3      (4-39)
```

因此，C3 的方法主张是“改善工况相关表示”，而不是“新增一项工况残差”。论文中不应把 `L_state` 或 `z_reg` 的距离直接描述为部署异常分数。

### 4.3.9 状态打乱负对照

为判断模型是否依赖正确的窗口—工况对应关系，在一个批次内对工况输入进行循环错配：

```text
z_reg^(n,shuffle) = f_regime(X^((n+1) mod B))                   (4-40)
```

主干仍读取原样本 `X^(n)`，但 FiLM 使用其他样本的工况嵌入。若 `film_true` 稳定优于 `film_shuffled`，说明正确工况配对具有额外信息；若两者相近，则不能排除性能变化仅来自参数量、正则化或随机扰动。

### 4.3.10 C3 的理论边界

C3 使用完整窗口，因此异常响应也会进入工况编码器。这是数据驱动通用性的代价：一方面，模型能利用完整模式区分复杂运行状态；另一方面，异常本身可能改变 `z_reg`，从而对主干进行不恰当调制。本文通过低维统计瓶颈、弱幅度 FiLM 和 shuffled 负对照限制并检验这一风险，但不能在理论上完全消除它。

因此，C3 是否有效必须由跨折结果决定，尤其要同时满足：

```text
film_true > baseline                                            (4-41)

film_true > film_no_aux                                         (4-42)

film_true > film_shuffled                                       (4-43)
```

上述不等式应在 AP、AUROC 和低误报指标上结合均值与方差判断，而不能仅引用单折最优结果。

## 4.4 C4：无响应泄漏的控制条件响应一致性模型

### 4.4.1 方法动机与条件预测假设

C4 建立如下正常性假设：在正常车辆群体中，给定一段电流和 SOC 控制轨迹，五类电—热响应应落在一个相对稳定的条件分布内：

```text
Y_1:T ~ p_normal(Y_1:T | C_1:T)                                 (4-44)
```

若真实响应显著偏离该条件分布，则说明系统输出与输入条件不一致。C4 使用神经动态模型估计条件中心：

```text
Y_hat_1:T = f_θ(C_1:T)                                          (4-45)
```

再以 `Y-Y_hat` 构造一致性残差。关键约束是 `f_θ` 的全部输入只能由 `I` 与 `SOC` 派生，真实响应不得进入编码器、潜变量或解码器。

C4 由四个模块组成：

1. control-only 双向 GRU 编码器；
2. 低维正则化控制状态瓶颈；
3. 控制派生序列驱动的响应解码器与一致性残差；
4. 正常集稳健标定与双分支限权融合。

### 4.4.2 模块一：控制序列提取

从完整输入按固定索引提取电流和 SOC：

```text
C_t = P_ctrl X_t = [I_t, SOC_t]                                 (4-46)
```

`P_ctrl` 是不可学习的通道选择算子。响应变量不进入 `C_t`。该硬约束使信息隔离具有代码层面的可验证性，而不是依赖模型自己忽略响应通道。

实现中使用响应扰动不变性测试验证信息隔离：固定 `I,SOC`，任意改变五个响应输入，预测 `Y_hat` 应严格不变：

```text
f_θ(C, Y) = f_θ(C, Y + ΔY) = f_θ(C)                             (4-47)
```

该测试只证明不存在响应到预测的计算路径，不代表模型一定能准确预测真实响应；预测能力仍需由正常验证误差和故障检测指标检验。

### 4.4.3 模块一：双向 GRU 控制动态编码

控制序列进入隐藏维度 `H_c=64` 的双向 GRU。正向 GRU 从 `t=1` 编码到 `T`，反向 GRU从 `T` 编码到 `1`：

```text
h_t^→ = GRU_f(C_t, h_(t-1)^→)                                  (4-48)

h_t^← = GRU_b(C_t, h_(t+1)^←)                                  (4-49)
```

以正、反向最终状态拼接为窗口级控制表示：

```text
h_C = [h_T^→ || h_1^←] ∈ R^(2H_c)                              (4-50)
```

若展开单个 GRU 单元，其更新过程为：

```text
r_t = sigmoid(W_r C_t + U_r h_(t-1) + b_r)                     (4-51)

g_t = sigmoid(W_g C_t + U_g h_(t-1) + b_g)                     (4-52)

h_tilde_t = tanh(W_h C_t + U_h(r_t * h_(t-1)) + b_h)           (4-53)

h_t = (1-g_t) * h_(t-1) + g_t * h_tilde_t                      (4-54)
```

门控结构允许编码器同时保留 SOC 的慢变化趋势和电流的快速变化信息。双向编码只用于完整窗口评分，不用于在线逐点未来预测；若部署场景要求严格因果在线检测，需要将其替换为单向编码器并重新验证。

### 4.4.4 模块二：低维控制状态瓶颈

由 `h_C` 计算 16 维均值与对数方差参数：

```text
μ = W_μ h_C + b_μ                                               (4-55)

ℓ = clip(W_ℓ h_C + b_ℓ, -8, 8)                                (4-56)
```

其中 `ℓ=log σ²`。训练和推理均使用后验均值作为确定性控制状态：

```text
z_ctrl = μ ∈ R^16                                               (4-57)
```

需要严谨说明：当前实现保留 VAE 式的均值/方差参数化和 KL 正则，但不执行随机重参数采样。因此它更准确地属于“KL 正则化的确定性潜变量瓶颈”，而不是完整的随机生成式 VAE。

KL 正则为：

```text
L_KL = -0.5·mean_j(1 + ℓ_j - μ_j² - exp(ℓ_j))                  (4-58)
```

其作用是约束潜变量不要无限增大或携带过度复杂的控制轨迹细节。由于 `z_ctrl` 仅由 `I,SOC` 生成，即使瓶颈容量较大，也无法包含真实响应值。

### 4.4.5 模块三：控制派生特征构造

仅使用原始 `I,SOC` 时，解码器需要自行学习若干明显的动态关系。为提高样本效率，构造五维控制派生输入：

```text
ΔI_t   = I_t - I_(t-1),      ΔI_1 = 0                          (4-59)

ΔSOC_t = SOC_t - SOC_(t-1),  ΔSOC_1 = 0                        (4-60)

U_t = [I_t, SOC_t, I_t², ΔI_t, ΔSOC_t] ∈ R^5                  (4-61)
```

各分量的作用如下：

- `I_t` 表示即时充电负载；
- `SOC_t` 表示电池工作区间；
- `I_t²` 为欧姆生热及电流强度非线性提供显式基函数；
- `ΔI_t` 表示负载突变；
- `ΔSOC_t` 表示荷电状态变化速率。

`I²` 的引入并不意味着模型已经显式实现焦耳热方程；它只是一个具有物理动机的输入基函数。因而本文将 C4 称为“控制条件响应一致性模型”，不将其夸大为白盒 ECM 或热模型。

### 4.4.6 模块三：响应序列解码

首先将控制状态映射为单向解码 GRU 的初始隐藏状态：

```text
h_0^dec = tanh(W_z z_ctrl + b_z)                                (4-62)
```

随后逐时刻输入 `U_t`：

```text
h_t^dec = GRU_dec(U_t, h_(t-1)^dec)                             (4-63)
```

线性响应头输出五个归一化响应预测：

```text
Y_hat_t = W_y h_t^dec + b_y ∈ R^5                              (4-64)
```

因此完整预测映射为：

```text
[I,SOC] → BiGRU → z_ctrl
                                       → Y_hat                  (4-65)
[I,SOC,I²,ΔI,ΔSOC] → GRU_decoder
```

式 `(4-65)` 中没有从 `Y` 到 `Y_hat` 的路径。真实响应只会在损失函数和评分函数中出现。

### 4.4.7 响应监督损失

在正常训练车辆上，使用 Smooth-L1 学习条件响应中心：

```text
L_resp = mean_(t,r) SmoothL1(Y_hat_t,r - Y_t,r)                 (4-66)
```

五个响应通道分别是：

```text
r ∈ {V_pack, V_max, V_min, T_max, T_min}                        (4-67)
```

输入已按训练数据的逐通道统计量归一化，因此式 `(4-66)` 在归一化空间中计算，电压和温度的原始单位差异不会直接支配损失。

### 4.4.8 C4 联合训练目标

C4 旁路与 MTAD-GAT 主干在同一次前向中并行计算，但不交换隐藏表示。总损失为：

```text
L_C4 = L_fore + L_rec + λ_C·(L_resp + λ_KL·L_KL)               (4-68)
```

当前正式配置为：

```text
λ_C  = 1.0
λ_KL = 0.0001                                                   (4-69)
```

`λ_KL` 较小，使模型优先学习控制—响应映射，同时以弱正则约束潜变量。C4 梯度会更新控制编码器和响应解码器；其辅助损失与基础损失共同反向传播，但 C4 输出不注入主干隐藏表示。

### 4.4.9 一致性残差向量

推理时，对每个时刻计算有符号响应残差：

```text
r_t = Y_t - Y_hat_t

    = [V_pack,t - V_hat_pack,t,
       V_max,t  - V_hat_max,t,
       V_min,t  - V_hat_min,t,
       T_max,t  - T_hat_max,t,
       T_min,t  - T_hat_min,t]                                  (4-70)
```

有符号残差保留了“实际响应高于或低于条件预测”的方向，便于后续机理分析；当前异常评分使用其绝对值。

窗口级一致性分数为全部时刻和五个响应维度的平均绝对误差：

```text
S_con = (1/(5T)) Σ_(t=1)^T Σ_(r=1)^5 |Y_t,r - Y_hat_t,r|       (4-71)
```

式 `(4-71)` 不包含 `I`、`SOC`、主干预测误差或主干重构误差。其含义是实际响应对由控制轨迹确定的典型正常响应的平均偏离程度。

### 4.4.10 模块四：正常训练集稳健尺度估计

主干分数与一致性分数来自不同模型，不能直接线性相加。设正常校准窗口集合上的两类分数分别为 `{S_base,i}` 与 `{S_con,i}`，计算稳健中心和 MAD：

```text
m_base = median_i(S_base,i)                                     (4-72)

d_base = median_i(|S_base,i - m_base|) + ε                      (4-73)

m_con  = median_i(S_con,i)                                      (4-74)

d_con  = median_i(|S_con,i - m_con|) + ε                        (4-75)
```

定义相对稳定性：

```text
q_base = d_base / (median_i|S_base,i| + ε)                      (4-76)

q_con  = d_con  / (median_i|S_con,i|  + ε)                      (4-77)
```

`q` 越小表示该分支在正常训练数据上的相对波动越低。

### 4.4.11 一致性分数尺度对齐

先将一致性分数转换为超过正常中心的单侧稳健偏离量：

```text
z_con^+ = max(0, (S_con - m_con) / d_con)                       (4-78)
```

再映射到主干分数尺度：

```text
S_con' = m_base + d_base·z_con^+                                (4-79)
```

使用单侧截断的原因是：C4 只把“高于正常中心的一致性误差”视为额外异常证据；低于正常中心的误差不应反向降低到不受控的负分数。

### 4.4.12 稳定性自适应限权融合

实现中的初始融合权重为：

```text
w_raw = q_base / (q_base + q_con + ε)                           (4-80)
```

若 C4 在正常集上比主干更稳定，即 `q_con < q_base`，则 `w_raw` 增大。为防止辅助分支压过主干，最终权重截断为：

```text
w = clip(w_raw, 0, w_max),     w_max = 0.35                     (4-81)
```

最终窗口分数为：

```text
S_final = (1-w)·S_base + w·S_con'                               (4-82)
```

所有中心、尺度和权重只使用正常训练/校准数据估计，测试标签不参与。C4 因此提供的是受限的辅助证据，而不是替换 MTAD-GAT 主分数。

### 4.4.13 车辆级高风险片段聚合

清华 EV 标签位于车辆级，而并非故障车辆的每个充电片段都表现为异常。设车辆 `v` 有 `M_v` 个片段分数，按降序排列：

```text
S_v,(1) ≥ S_v,(2) ≥ ... ≥ S_v,(M_v)                             (4-83)
```

取比例 `ρ=0.05`，令 `K_v=max(1, ceil(ρM_v))`，车辆分数为：

```text
S_vehicle,v = (1/K_v) Σ_(k=1)^(K_v) S_v,(k)                    (4-84)
```

Top-5% 聚合兼顾最大分数对噪声的敏感性和全均值对稀疏故障片段的稀释问题。

### 4.4.14 C4 的可识别性与局限

control-only 模型只能学习 `E[Y|I,SOC]` 及其时序近似。如果环境温度、车辆内阻、老化程度、冷却状态和传感器偏置等未观测变量显著影响响应，则同一 `I,SOC` 可能对应多个正常响应：

```text
Y = f(I,SOC,Z_unobserved) + noise                               (4-85)
```

而当前模型只估计：

```text
Y_hat ≈ E_Z[f(I,SOC,Z)]                                        (4-86)
```

此时正常个体差异也会产生较大 `S_con`。因此 C4 的有效性不能只由训练响应损失判断，必须同时检查正常车和故障车的一致性分数分布、跨折稳定性以及融合后的低误报性能。

## 4.5 C3、C4 与 DyAD 的方法边界

### 4.5.1 C3 与 C4 的本质区别

| 对比维度 | C3 | C4 |
|---|---|---|
| 研究问题 | 当前窗口属于何种统计模式 | 给定控制轨迹时响应是否合理 |
| 模型输入 | 完整七通道窗口 | 仅电流与 SOC |
| 响应变量是否作为模型输入 | 是 | 否 |
| 输出 | 8 维工况嵌入 | 五通道响应预测 |
| 作用位置 | MTAD-GAT 融合表示内部 | 与 MTAD-GAT 平行的独立旁路 |
| 是否产生独立分数 | 否 | 是，产生 `S_con` |
| 知识来源 | 全数据驱动统计模式 | 控制—响应角色先验 + 数据学习 |
| 主要风险 | 异常进入工况嵌入并影响调制 | 未观测正常个体差异造成误报 |

C3 的简化信息流为：

```text
完整 X → 统计描述 d → z_reg → FiLM(H) → 主干预测/重构 → S_base,C3   (4-87)
```

C4 的简化信息流为：

```text
I,SOC → z_ctrl,U → Y_hat
                         → S_con → 稳健融合 → S_final               (4-88)
真实 Y ──────────────────┘
```

### 4.5.2 C4 与 DyAD 的区别

Zhang 等提出的 DyAD 将控制量记为 `x0`、响应量记为 `x1`。其核心信息流为：

```text
z_DyAD = Encoder(x0, x1)                                       (4-89)

x1_hat = Decoder(z_DyAD, x0)                                   (4-90)
```

因此，DyAD 的潜变量在生成响应前已经读取真实响应。它学习的是完整片段的条件动态重构。

本文 C4 为：

```text
z_ctrl = Encoder(x0)                                            (4-91)

x1_hat = Decoder(z_ctrl, x0)                                   (4-92)
```

预测器全程不访问 `x1`。二者的区别不是简单减少输入维度，而是改变了残差含义：

```text
DyAD residual：完整片段经过条件自编码后能否重构

C4 residual：真实响应是否偏离控制量能够独立预测的正常响应          (4-93)
```

此外，DyAD 是独立检测器，并带有里程监督；本文 C4 不使用里程监督，而是把无响应泄漏一致性分数作为 MTAD-GAT 的受限辅助证据。

## 4.6 模型训练与推理流程

### 4.6.1 C3 训练流程

```text
输入正常窗口 X
  ├─→ MTAD-GAT 三路主干 → H
  └─→ 28维统计描述 d → 8维 z_reg → {γ,β}
                                  ↓
                              FiLM(H)
                                  ↓
                       预测头与重构头 → L_fore + L_rec
                                  ↑
                  z_reg → d_hat → λ_state·L_state
```

### 4.6.2 C4 训练流程

```text
输入正常窗口 X
  ├─→ MTAD-GAT 主干 → L_fore + L_rec
  ├─→ 选择 I,SOC → 控制编码器 → z_ctrl
  │                    ↓
  │   [I,SOC,I²,ΔI,ΔSOC] → 响应解码器 → Y_hat
  │                                         ↓
  └─→ 选择真实响应 Y ─────────────────→ L_resp

总损失：L_fore + L_rec + λ_C(L_resp + λ_KL L_KL)
```

### 4.6.3 C4 推理流程

```text
MTAD-GAT(X) → S_base

ControlModel(I,SOC) → Y_hat
真实 Y 与 Y_hat 比较 → S_con

正常集统计量校准(S_base,S_con) → w 与尺度对齐

S_final = (1-w)S_base + wS_con'

窗口分数 → Top-5% 片段聚合 → 车辆分数
```

## 4.7 实验设计与判定标准

### 4.7.1 C3 四臂实验

| 实验臂 | FiLM | 语义辅助损失 | 状态配对 | 目的 |
|---|---:|---:|---:|---|
| `baseline` | 否 | 否 | 无 | 原始主干参照 |
| `film_no_aux` | 是 | 否 | 正确 | 判断纯 FiLM 作用 |
| `film_true` | 是 | 是 | 正确 | 完整 C3 |
| `film_shuffled` | 是 | 是 | 批内错配 | 检验正确工况语义 |

只有当 `film_true` 相对 baseline 的增益跨折稳定，并且总体优于 shuffled，才能支持“正确工况调制有效”的结论。

### 4.7.2 C4 两臂主实验与内部评分消融

模型训练比较为：

| 实验臂 | control-only 分支 | 目的 |
|---|---:|---|
| `baseline` | 否 | MTAD-GAT 参照 |
| `control_only` | 是 | 新版 C4 |

同一个 C4 checkpoint 还应报告三类评分：

```text
1. S_base：只使用 MTAD-GAT 主干；
2. S_con：只使用控制—响应一致性残差；
3. S_final：正常集稳健融合。
```

这一区分能够判断性能变化究竟来自联合训练对主干的正则化，还是来自推理阶段加入独立一致性分数。

### 4.7.3 评价指标

主指标为车辆级 Average Precision（AP），辅助指标包括 AUROC、`TPR@FPR≤1%`、`TPR@FPR≤5%`、校准阈值下的误报率以及五折均值和标准差。由于故障车辆比例不平衡，AP 比单一准确率更适合作为主指标。

### 4.7.4 当前复验计划

| 路线 | 配置 | 实验规模 |
|---|---|---:|
| C3 全窗口调制 | `configs/internal/92_c3_full_window_brand3_paper_fivefold.json` | 四臂 × 五折 = 20 |
| C4 control-only | `configs/internal/93_c4_control_only_brand3_paper_fivefold.json` | 两臂 × 五折 = 10 |

C4 配置已显式固定 `λ_C=1.0`，避免继承通用辅助损失默认值而导致论文公式与实际训练不一致。

## 4.8 计算复杂度分析

C3 的统计描述计算复杂度为 `O(BTD)`，MLP 和 FiLM 参数生成相对于 MTAD-GAT 主干开销很小。FiLM 调制本身为逐元素运算，复杂度同样为 `O(BT·3D)`。因此 C3 的主要额外成本来自一个小型工况 MLP，而非新的时序主干。

C4 增加一个输入维度为 2、隐藏维度为 64 的双向 GRU，以及一个输入维度为 5、隐藏维度为 64 的单向 GRU。其时间复杂度近似为：

```text
O(BT·H_c²) + O(BT·H_d²)                                        (4-94)
```

空间复杂度主要由两个 GRU 的中间状态决定。C4 与主干并行，不增加 Feature-GAT 或 Temporal-GAT 的图注意力复杂度。

## 4.9 本章小结

本章针对多工况动力电池异常检测中的两类混淆因素，提出了具有明确边界的 C3 与 C4 路线。C3 使用完整窗口的水平、波动、趋势和局部变化统计构造连续工况嵌入，并通过恒等初始化、弱幅度 FiLM 在融合层调制 MTAD-GAT 表示；状态语义重建损失进一步约束工况嵌入保留可解释的窗口统计信息。

C4 则建立严格的响应不可见信息流。其编码器只读取电流和 SOC，解码器只读取控制量及其派生动态特征，真实电压与温度仅用于训练监督和推理残差。由此得到的控制条件响应一致性分数经正常集 MAD 标定后，以不超过 0.35 的权重与主干统计异常分数融合。

两条路线分别回答不同问题：

```text
C3：当前窗口属于何种统计运行模式？

C4：当前电—热响应是否符合该控制轨迹下的正常规律？
```

最终是否能够改善故障车辆排序和低误报检测能力，将由清华 EV Brand3 严格五折复验确定。
