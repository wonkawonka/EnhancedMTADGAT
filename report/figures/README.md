图形布局参考 MTAD-GAT 原论文 Figure 2，采用单主干流程而非多面板总览。实线表示前向数据流，橙色虚线表示训练约束；蓝灰色模块表示 MTAD-GAT 主干或第三章继承模块，橙色模块表示对应章节的新增设计。

两张图均为 1800×700 的紧凑横向布局。第三章展开动态上下文编码与关系融合表示上的 FiLM 条件化；第四章只展开新增的物理状态编码、响应一致性和最终评分融合。变量图、时间图和各响应公式放在正文中，避免总体架构图过载。
