## 模块贡献

1. 条件校准幅值比 Raw 的 F1 提高约 3.85 个百分点，Recall 提高约 2.22 个百分点、FPR 降低约 3.33 个百分点；AUROC 没有提高。它改善了当前阈值下的工作点，但不能据此声称排序能力全面更强。
2. B1 Full 融合 F1 比 Lite 融合低约 7.70 个百分点，AP 仅高约 0.17 个百分点；Full 融合 Recall 更低，FPR 也更低，因此需要同时看阈值工作点，不能把 F1 差异全部解释为表示退化。Full 的 relation 原值 AP/AUROC 也弱于 Lite relation，当前证据不支持复杂关系头优于简化统计关系。
3. B4 简化融合与 Full 几乎持平，AP 高约 0.07 个百分点，AUROC 高约 0.19 个百分点，F1 低约 0.14 个百分点。B1/B4 同时改变 Graph 和 FiLM，不能单独判断哪个模块冗余。车辆聚类 bootstrap 的 AP/AUROC 差值区间均跨 0，当前证据也不足以证明等效。
4. Full 等权融合弱于幅值原值，也弱于幅值CDF的 F1。CDF 转换后的幅值 AP 从 0.8728 降到 0.8337；窗口CDF后再聚合可能改变车辆排序并产生饱和，需要审查该顺序与关系分支的互补性。不能依据测试标签调整 alpha 后当作正式提升。

### 三seed结果的解释

1. 关系头第二个变量图可作为简化候选：B2−B1 在LFP的AP/AUROC略升，在NCM略降，但两个体系均满足原计划工程非劣判据。这只涉及冻结骨干之后的关系图，不涉及骨干变量图，也不表示完全等效。
2. FiLM的检测收益主要出现在LFP：去掉FiLM（B4−B2）后AP约下降0.99个百分点、Recall约下降2.74个百分点，AP差值区间全为负，且不满足非劣判据；NCM差异较小并满足简化判据。不能把NCM或Brand3结果推广成FiLM普遍无用。
3. linear FiLM可作为条件编码简化候选：B5相对B2在LFP的AP/AUROC略低，但Recall/F1更高；两个体系均满足工程非劣判据。它不等于MLP没有排序价值，只表示当前固定骨干下的下降在预设容忍范围内。
4. Transformer与Dense MLP存在体系差异：LFP的B2排序优于B3；NCM的B3排序优于B2，误报更低。Dense MLP参数更多但实际epoch训练更快，不能把结果归因于“更小容量”或注意力本身；也没有一个结构在所有数据集占优。
5. LFP有残差关系收益：B2关系单支平均AP/F1为0.8315/0.5192，优于Lite关系单支0.7885/0.4272及线性LOO关系单支0.7983/0.4399；B2融合F1为0.4956，低于自身关系单支。NCM神经头与Lite的F1差异很小，Brand3则仍是Scale更好。因此关系学习应定位为场景依赖收益，固定等权融合需要后续独立验证，不能用测试最优alpha替代原协议。

LFP 的关系单支确有收益，因此不能把 Brand3 的负结果概括成“关系模块无用”。更准确的表述是：工况校准改善残差评分，关系分数能补充部分异常信息，但收益随化学体系和车辆队列变化；关系结构复杂度与融合方式需要独立检验。

当前可以保留的研究主线是“条件校准 + 场景依赖的残差关系建模”，尚不能声称 Graph+Transformer+FiLM 全套模块普遍必要。阶段B已完成B1/B2关系图、B2/B4 FiLM、B2/B5非线性调制及B2/B3实际结构效果/成本对照；具体结论以三seed点估计、VIN区间和预设工程判据为准。
