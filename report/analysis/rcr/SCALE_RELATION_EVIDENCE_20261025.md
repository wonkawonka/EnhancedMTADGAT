# Brand3 尺度退化归因与 CH/Brand3 关系互补性验证（2026-10-25）

**结论：Brand3 的主要退化来自随工况变化的公共尺度因子；全局收缩能够恢复原有表现，但尚未证明条件尺度稳定优于原 RCR。关系分支的可信互补证据集中在 NCM；LFP 与 Brand3 尚不支持普遍获益。**

任务 `RCR-SCALE-RELATION-EVIDENCE-20261025-v1`。5 个 Brand3 尺度单元、7 个关系单元全部完成；复用冻结 Backbone 和完整窗口评分，不重新训练编码器。本文是独立机制验证，未修改最终四张论文实验矩阵。

## 1. Brand3：尺度损失发生在哪里

保持条件均值 μ 完全不变，不加可靠性门控。全局尺度分别使用正常训练去均值能量的 RMS，以及正常窗口 RMS 中位数；后者仅对窗口级尾部稳健，不是逐点 MAD。连续条件尺度仍取此前正常验证选出的 log-RMS 模型。

Brand3 均为五折等权；同一九辆故障车跨折重复，不把 45 次故障测试当作 45 辆独立故障车。正常验证每折仅 18–19 辆，阈值 P95 的经验分辨率约为 1/18，测试 FPR 可明显偏离 5%。

将条件尺度精确分为 `sigma_i(c)=s_global,i × a(c) × r_i(c)`，其中 `a(c)` 为七变量尺度比的几何均值，`r_i(c)` 的跨变量几何均值为 1。公共因子只改变一个窗口的整体强度，相对尺度只改变变量权重。重新执行同样 Top-5% 聚合后：

- 全局 RMS → 完整连续条件尺度的 AUROC 差值 -0.1316 [-0.2533, -0.0374]。
- 全局 RMS → 只保留公共因子的 AUROC 差值 -0.1341 [-0.2487, -0.0466]。
- 全局 RMS → 只保留变量相对尺度的 AUROC 差值 +0.0172 [-0.0046, +0.0489]。
- 相对尺度 → 完整条件尺度的 AUROC 差值 -0.1488 [-0.2608, -0.0563]。

因此，主要损失不能归结为固定的变量权重或单个极小尺度：公共工况归一化本身已复现大部分退化。删除单变量的七项事后诊断也未将完整连续尺度恢复到原 RCR（完整数值见 `all_metrics.csv`）。相对尺度的较好点估计属于归因对照，不能据此在测试集反选新检测器或宣称它已获得独立验证。

| 测试样本 | 公共尺度因子窗口中位数（五折平均） | 超出训练 q 半径 P99 占比 |
| --- | --- | --- |
| 正常 | 0.7219 | 1.11% |
| 故障 | 1.0253 | 4.24% |

公共尺度与未归一化去均值能量的窗口级 Spearman 相关，五折平均为 0.5097。高能量样本也常获得较大分母，导致排序被压缩。这是固定模型的反事实归因，不能仅凭相关或高尺度就断定故障信息被模型主动抹除；正常工况组成差异与外推均可能参与。逐折支持域、截断比例、逐变量权重和状态内标准化能量均已保存。

将超出训练 q 半径 P99 的测试窗口剔除、重新按车辆 Top-5% 聚合后，全局 RMS AUROC=0.8969，完整条件尺度=0.7665，只保留公共因子=0.7519。这项事后支持域诊断仍使用同一批保留下来的车辆比较各分数，提示退化并非仅由外推窗口造成；保留车辆数量与逐折结果见 `in_support_ranking_diagnostic.csv`。

## 2. 稳健尺度与全局尺度收缩

固定网格 λ∈{0,0.25,0.5,0.75,1}，使用 `sigma²=(1−λ) sigma_global²+λ sigma_conditional²`。λ=0 是全局，λ=1 是完整条件尺度。两类尺度共 10 个候选全部报告，不按测试 AP 选择。

| --- | --- | --- |
| 0 | 0.8679 / 0.9129 / 0.7062 | 0.8720 / 0.9153 / 0.6903 |
| 0.25 | 0.8492 / 0.8956 / 0.6414 | 0.8603 / 0.9043 / 0.6604 |
| 0.5 | 0.8186 / 0.8713 / 0.6105 | 0.8413 / 0.8884 / 0.6487 |

| 折 | 正常 VIN NLL 选择 | 一标准误选择 | 原口径窗口等权 NLL 选择 |
| --- | --- | --- |
| Brand3_fold0 | log_lambda025 | log_lambda000 | log_lambda025 |
| Brand3_fold1 | log_lambda025 | log_lambda000 | log_lambda025 |
| Brand3_fold2 | log_lambda050 | log_lambda000 | log_lambda075 |
| Brand3_fold3 | log_lambda025 | log_lambda000 | log_lambda025 |
| Brand3_fold4 | log_lambda025 | log_lambda000 | log_lambda050 |

一标准误规则：在最小正常验证 VIN 等权 NLL 加该候选 VIN 标准误范围内，选 λ 最小者；同 λ 时按正常 NLL 选尺度族。标准误来自完整 VIN，不把窗口当独立验证对象。该规则预先固定，未读取测试指标。原窗口等权选择另行复核，避免将 VIN 重加权与尺度收缩混淆。

- 稳健条件尺度相对原 RCR：AUROC -0.0897 [-0.1715, -0.0213]。稳健化能减轻连续尺度退化，仍未恢复原 RCR。
- VIN NLL 最优收缩相对原 RCR：AUROC -0.0261 [-0.0718, +0.0073]。
- 原窗口等权 NLL 选择相对原 RCR：AUROC -0.0397 [-0.0869, -0.0030]。
- 一标准误收缩相对上一轮所选条件尺度：AUROC +0.1129 [+0.0367, +0.2128]；相对原 RCR为 -0.0027 [-0.0563, +0.0444]。

**条件分布建模的可靠空间：当前可支持的是加入保守回退，避免不可靠条件尺度伤害原有评分；尚无证据支持在 Brand3 上让完整条件方差成为主分数。保留变量相对尺度、限制公共因子是后续候选，应在新的独立划分上确认，不能把这次归因对照的测试高点当正式改进。**

正常验证 VIN 等权 NLL 的五折均值：全局 RMS -4.9217，λ=0.25 为 -4.9324，完整连续条件尺度 -4.8401（越低越好）。加入全局 RMS 对照后，完整条件尺度在正常验证本身也不占优；部分收缩的正常拟合小幅改善仍没有转化为检测收益，不能把正常 NLL 当异常 AP 的替代目标。

## 4. 在相同验证报警预算下，互补信息能否转为收益

固定 0.5 权重，将正常训练 CDF 后的 A 与 LOO 在窗口层融合，再按原协议聚合；阈值由各方法正常验证 P95 确定。补充 max-CDF 融合，对联合分数重新定正常验证阈值；直接对两个 P95 报警取 OR 只作覆盖诊断，其验证 FPR 与新增误报另存，不能作为同预算提升。

NCM 的关系融合相对 A-CDF 的 AUROC 差值为 +0.0080 [+0.0043, +0.0118]；相对 A+对角边缘融合仍为 +0.0054 [+0.0025, +0.0088]。条件 LOO 相对同输入对角评分为 +0.0062 [+0.0009, +0.0120]，相对无条件 LOO 为 +0.0053 [+0.0026, +0.0084]。这些结果支持 NCM 的收益包含条件联合关系信息，不能只由 CDF 或边缘重加权解释。

P99 敏感性检查：NCM 融合的排序优势保持；但相对 A 的 Recall 差值为 +0.0005 [-0.0088, +0.0106]，F1 差值为 +0.0016 [-0.0075, +0.0112]，均跨零。因此，实际报警收益目前主要在主协议 P95 下获得支持，不能声称对更严格阈值同样稳定。

## 5. 证据边界与产物

- 全部指标保持原训练/验证/测试划分、Backbone、Top-5% 聚合及 `score >= threshold` 判定。P95 为主，P99 为预定敏感性检查；`all_metrics.csv`、`paired_VIN_intervals.csv` 含全部结果。
- 500 次标签分层 VIN 成组配对 bootstrap，seed3407；同 VIN 的相关片段共享权重，Brand3 跨折重复车辆也共享权重。Brand3 折均值区间不把折视为独立样本。区间固定训练模型与验证阈值，不包含重训练或阈值估计不确定性；未作多重比较校正。
- `scale/*/fault_normal_rank_pairs.csv` 为车辆级正常/故障排序翻转，`variable_scale_diagnostics.csv` 为尺度与能量贡献，`state_tail_diagnostics.csv` 为工况内 NLL/尾部，`state_support_diagnostics.csv` 为外推与公共尺度摘要。
- `normal_selection_audit.csv` 和各尺度 `selection.json` 保存正常选择记录；原窗口等权选择保存在 `supplement/`，不篡改主任务。
- `relation/*/prediction_sets.csv`、`error_overlap.csv` 保存错检/漏检集合与分组计数，`unbudgeted_OR_diagnostic.csv` 保存未经联合报警率控制的 OR 代价。
- 直接重放能量与原始分数一致性见每单元 `audit.json`；主分数 CSV 均用 `float_precision="round_trip"` 回读以保留并列分数。

**设计优先级：Brand3 优先保留全局尺度回退，暂不升级复杂条件分布网络；关系模型优先围绕 NCM 已观察到的高内阻、低容量补检，使用独立数据确认联合关系收益。**
