# RCR V1 模型与消融对比报告

**本报告只将已有完整评估指标的实验单元填为数值；Brand3 五折结果见下表。**

## 模型架构与命名

这里的 CDF 是正常训练分数的经验累积分布函数：将分数映射为它在正常样本中的分位位置，再融合不同量纲的幅值与关系分数。例如 0.95 表示高于约 95% 的训练正常分数；它不是新模型，也不使用测试标签。极端值都可能映射到上界 1，故需注意饱和。

![RCR V1 实际实现架构](RCR_ARCHITECTURE.svg)

共享骨干为“变量嵌入 → 全局变量图 → 2 层时间 Transformer → 确定性重构”。残差经电流/SOC 的 8 维人工统计量做线性均值/尺度校准；这里没有可学习的条件编码器。Lite 用 Ledoit–Wolf 精度矩阵二次型衡量变量关系；Net 对每个残差坐标做遮蔽留一预测，使用一套共享变量图、1 层变量注意力及可选条件 FiLM。两条关系分支是互斥对照，不是串联；Raw、Scale、Lite、Net 共用骨干，不是四套独立模型。骨干先以 Huber 重构损失训练并冻结，Net 关系头随后以掩码预测 MSE 单独训练，因此当前模型不是重构损失与关系损失端到端联合优化。幅值与关系分数各由训练正常经验 CDF 映射后固定 α=0.5 融合，阈值只用正常验证集。**实际实现不含 TCN、可学习条件编码器、概率解码器、多尺度 Transformer、掩码邻接损失或原计划的 newC3 模块。**详见 [PROTOCOL.md](PROTOCOL.md)。

**条件消融**固定重构骨干与关系建模主形式，改变工况信息的使用方式：无条件、充放电 one-hot、连续电流/SOC 统计量，以及关系头是否使用 FiLM。它检验收益是否来自工况校准或条件调制。

**架构消融**固定工况定义与评分协议，移除或替换模型的结构部件：骨干变量图、时间 Transformer，以及 Lite/Net 关系建模。它检验表征与关系结构本身是否必要。前者改变“如何使用工况”，后者改变“由什么结构学习”。

实验采用正常充放电混合、VIN隔离，seed3407。RCR只在正常数据训练，epoch由正常验证loss选择；主融合alpha=0.5，阈值由正常验证片段P95/P99确定，不使用测试标签挑alpha、epoch或阈值。

## 比较边界

- † 为既有预算参考：10epoch、最多100k训练窗口；RCR为全量正常训练、backbone最多50epoch及关系头最多30epoch、patience8。两者不是等训练预算，不能将全部差异归因于结构。
- 主机制比较是同一冻结backbone与校准下的Raw/Scale/Lite/Net。Net是否超过Lite必须独立报告，不能只比较原MTAD-GAT。

- LFP/NCM分别训练，不是零样本迁移。单seed与反复使用公开研究队列限制确认性结论。

## 校准机制验证：收益来自条件均值，而非当前尺度路径

本实验冻结同一重构骨干，不重新训练模型。比较原始残差、只减去条件均值，以及五个预先固定的 `min_std`：0.005、0.01、0.02、0.05、0.10。所有 `μ(q)`、`σ(q)` 和经验 CDF 只由正常训练残差拟合；`min_std` 只按正常验证集 Gaussian NLL 选择，不使用测试标签。下表采用与主表相同的正常验证 P95 阈值和样本 Top-5% 聚合，单元格顺序为 AUROC / AP / F1 / Recall / FPR。

正常验证 NLL 在候选中选择 0.005（LFP -5.2977，NCM -5.2979），但这只能说明候选中更小的常数更合适：0.005 仍比典型残差尺度高几十至上百倍，拟合后的 `σ(q)` 继续贴住下限。因而当前 Scale 相对 Raw 的明显提升来自 `μ(q)` 消除了工况相关残差偏置；没有证据表明条件尺度变化参与了样本排序。若继续验证异方差机制，候选范围应降至约 1e-5–1e-3，并仍只用正常验证数据选择。

## 关系头内部结构消融

本实验固定同一个 frozen backbone、`min_std=0.05` 的同一标准化残差、连续条件 FiLM、30% 随机遮蔽、训练预算、CDF 融合和正常验证阈值，仅替换关系预测结构。Dense MLP 对全部 masked 变量 token 做稠密混合；Graph-only 只保留关系头 VariableGraph；Transformer-only 只保留沿变量轴的自注意力；Full 为当前第二个 VariableGraph 加变量 Transformer。以下均为 seed3407 单次结果。

LFP 中，Full 的融合 AUROC 只比 Transformer-only 高 0.0013，而 Transformer-only 的 F1、Recall 和 FPR 更好；关系分数单独使用时，Transformer-only 的 AP/F1/Recall 也略高。NCM 中，Dense MLP 的 AUROC/AP/FPR 最好，Transformer-only 的融合 F1/Recall 最好，Full 没有任何主要指标第一。按故障类型分层也没有出现第二个 VariableGraph 的稳定优势：例如 LFP 充电高内阻 Recall 为 Transformer-only 0.6246、Full 0.6075；NCM 充电低容量为 0.7800、0.7433，但 NCM 放电高内阻则 Full 0.5767、Transformer-only 0.5467。

因此，现有单 seed 证据支持“变量自注意力有一定价值”，但不支持“关系头中的第二个 VariableGraph 稳定增加关系建模能力”。更简单的 Masked residual＋FiLM＋Variable Transformer 是当前更有依据的关系头候选；在多 seed 确认前，不能把删除第二个图写成最终结论。

## 预设主比较：RCR-Net − RCR-Lite

- LFP：auroc +0.0199, ap +0.0211, f1 +0.0377, recall +0.0326, fpr -0.0038。
- NCM：auroc +0.0019, ap -0.0007, f1 -0.0043, recall -0.0069, fpr -0.0040。

上述差值不自动证明成功。尤其F1/Recall提高若伴随FPR上升，不是等误报预算增益；单个setting正向也不满足方案要求的跨setting稳定优势。
