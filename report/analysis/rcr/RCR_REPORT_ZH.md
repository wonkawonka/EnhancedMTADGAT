## 模型架构与命名

这里的 CDF 是正常训练分数的经验累积分布函数：将分数映射为它在正常样本中的分位位置，再融合不同量纲的幅值与关系分数。例如 0.95 表示高于约 95% 的训练正常分数；它不是新模型，也不使用测试标签。极端值都可能映射到上界 1，故需注意饱和。

![RCR V1 实际实现架构](RCR_ARCHITECTURE.svg)

共享骨干为“变量嵌入 → 全局变量图 → 2 层时间 Transformer → 确定性重构”。残差经电流/SOC 的 8 维人工统计量做线性均值/尺度校准；这里没有可学习的条件编码器。Lite 用 Ledoit–Wolf 精度矩阵二次型衡量变量关系；Net 对每个残差坐标做遮蔽留一预测，使用一套共享变量图、1 层变量注意力及可选条件 FiLM。两条关系分支是互斥对照，不是串联；Raw、Scale、Lite、Net 共用骨干，不是四套独立模型。骨干先以 Huber 重构损失训练并冻结，Net 关系头随后以掩码预测 MSE 单独训练，因此当前模型不是重构损失与关系损失端到端联合优化。幅值与关系分数各由训练正常经验 CDF 映射后固定 α=0.5 融合，阈值只用正常验证集。**实际实现不含 TCN、可学习条件编码器、概率解码器、多尺度 Transformer、掩码邻接损失或原计划的 newC3 模块。**详见 [PROTOCOL.md](PROTOCOL.md)。

**工况消融**只保留完整Net与“Net无全部条件”，考察电流/SOC工况信息整体是否有效；one-hot、FiLM形式等细分设置移至详细归档。

**架构消融**固定工况定义与评分协议，移除或替换模型的结构部件：骨干变量图、时间 Transformer，以及 Lite/Net 关系建模。它检验表征与关系结构本身是否必要。前者改变“如何使用工况”，后者改变“由什么结构学习”。

实验采用正常充放电混合、VIN隔离，seed3407。RCR只在正常数据训练，epoch由正常验证loss选择；主融合alpha=0.5，阈值由正常验证片段P95/P99确定，不使用测试标签挑alpha、epoch或阈值。

## 校准前后残差分布验证

固定已有骨干、校准参数和数据划分，仅复算缓存，不重新训练或调参。完整报告及8组PNG/PDF见[校准前后分布诊断](../rcr_calibration_distribution_20261024/README.md)。下表比较共享骨干的Raw与Scale幅值评分，不代表RCR-Net整体结构的对比结果。

| 诊断（原始 → 校准） | LFP | NCM |
| --- | --- | --- |
| 正常有符号残差均值的工况η²，越低越好 | 0.1985 → 0.0501 | 0.2485 → 0.0650 |
| 正常残差标准化Wasserstein，越低越好 | 0.4810 → 0.3867 | 0.4602 → 0.2960 |
| 整体AUROC | 0.6147 → 0.7715 | 0.7931 → 0.8189 |
| 整体AP | 0.7387 → 0.8113 | 0.8602 → 0.8755 |
| 正常最终log幅值评分的工况η² | 0.2175 → 0.2156 | 0.1740 → 0.1234 |
| 粗分层AUROC下降数（充放电×故障类型） | 0/6 | 0/6 |
| 细工况组AUROC下降数 | 1/41 | 15/43 |

**结论：正常残差均值的工况差异缩小，整体故障可分性改善；全局收益和局部损失同时存在。** LFP最终幅值评分的工况依赖仍明显。NCM放电、电流低分位/SOC中分位的高内阻组，AUROC由0.8347降至0.7849；ΔAUROC的VIN配对95%区间为[−0.0907, −0.0136]，正常/故障片段85/78、车辆45/26。NCM共有4个细工况组的未校正区间完全低于0。这些是事后探索结果，未作多重比较校正；粗分箱也不等于连续工况严格匹配，需要独立数据确认。

机制检查发现，两体系现有尺度σ均约为0.05，Scale排序与仅条件去均值相同，本轮收益主要来自去均值。给定工况和参数，校准变换可逆；局部下降指当前幅值评分的可分性损失，不能称为原始信息永久丢失。

可以据此提出研究问题：**如何消除正常工况偏置，同时保留不同工况下的故障证据？** 原始/校准残差并行、按正常条件支持度约束融合是待验证候选。应先排查尺度下限，再以相同骨干和预算进行模块对照及多seed、独立品牌验证；当前结果尚未证明新架构有效。

### 信号重构/预测误差：MAE 与 MSE

这里比较模型输出与真实输入信号，不比较异常分数与0/1标签。单元格顺序为 **MAE / MSE**，均越低越好；与P95/P99阈值无关，故每个体系只列一次。

定义：$\mathrm{MAE}=N^{-1}\sum_i|\hat{x}_i-x_i|$，$\mathrm{MSE}=N^{-1}\sum_i(\hat{x}_i-x_i)^2$。

- 补算统一取每个模型输出的窗口末时刻、全部7个变量，与同一时刻输入比较；对所有测试窗口和变量等权求均值，含正常及故障样本，不取Top-5%。重叠窗口按原stride=4取末时刻；TranAD原生窗口10，其余32。MTAD-GAT主表取重构输出，预测头误差另存于明细。
- 所有补算只加载已保存checkpoint，model.eval()，不重新训练、不改变检测指标。明细同时保存正常/故障分组误差、checkpoint哈希与样本映射哈希。尚未补算的历史MSE暂保留其原生窗口目标，见signal_errors.csv的target；不能与统一末时刻目标混比。
- 数值位于各自训练正常MinMax归一化空间；不同小波分量分别拟合Scaler，不能把不同输入列的误差大小直接解释为故障检测能力。
- `待补`：未保存足够的逐点输出/误差，需加载原模型补做推理。MAE不能从MSE、训练loss或异常分数反推。MTAD-GAT的预测/重构融合分数、Anomaly Transformer的关联加权分数、PatchAD的复合分数均不能直接当作纯重构MSE。
- `不适用`：当前DCdetector、Isolation Forest和最终Deep SVDD模型无信号重构/预测输出。
- MAE、MSE按同一模型行内取最小值并加粗；只比较已经补算为统一末时刻目标的单元。分量各自缩放且预测目标不同，误差最小不等于检测能力最强，也不用于跨模型排名。
