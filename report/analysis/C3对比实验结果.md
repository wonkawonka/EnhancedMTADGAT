# 统一外部 baseline 与完整 C3 对比实验报告

生成日期：2026-08-26

## 1. 报告范围

本报告只整理两类结果：

1. 任务 07 的统一外部 baseline 对比实验；
2. 任务 100/101 的完整 C3（`prototype-query`）正式结果。

任务 103 的 `No-Aux`、`Shuffled State (Farthest)` 等机制消融不放入本报告，避免将消融实验与外部方法对比混在一起；相关结果见 [`实验结果_103_06.md`](实验结果_103_06.md)。

任务 103/06 的完整实验背景另见 [`实验结果_103_06.md`](实验结果_103_06.md)。

## 2. 实验来源与状态

## 3. 评价口径

| 数据集 | 主要指标 | 说明 |
|---|---|---|
| MSL、SMAP | 原始点级 AP、AUROC | 用于比较 anomaly score 排序能力 |
| Brand3 | 车辆级 PR-AUC、AUROC | 5 folds × 3 seeds 汇总 |
| BMS | FAR、每万窗口误报 | 只有正常样本，不报告 AP/AUROC/F1 |

任务 07 的 F1 使用 q0.99 正常验证阈值；任务 100/101 的完整 C3 使用其正式训练/评估阈值流程。因此本报告的主比较使用 AP、AUROC 和 Brand3 车辆级 PR-AUC/AUROC，F1 不作为跨任务主结论。

完整 C3 相对于 C3 内部 MTAD-GAT baseline 仅有小幅提升：Vehicle PR-AUC +0.0025、AUROC +0.0039，且标准差较大。相对于任务 07 的 AutoEncoder、Isolation Forest、LSTM-AD 和 USAD，完整 C3 仍有明显差距。因此 Brand3 当前只能支持“完整 C3 相对内部 baseline 有轻微改善”，不能支持“完整 C3 超过外部 baseline”。

## 8. 最终对比结论

| 数据集 | 外部 baseline 最佳 | 完整 C3 | 结论 |
|---|---|---|---|
| MSL | TranAD AP=0.172846；LSTM-AD AUROC=0.643045 | AP=0.246917；AUROC=0.716749（seed=3407） | 完整 C3 明显领先已完成外部 baseline |
| SMAP | Deep SVDD AP=0.172161、AUROC=0.626808 | AP=0.125179；AUROC=0.444014（干净 seed=3407） | 完整 C3 当前低于内部 baseline 与外部强 baseline |
| Brand3 | AutoEncoder AP=0.789687、AUROC=0.857245 | AP=0.5221±0.0834；AUROC=0.7248±0.0595 | 完整 C3 相对内部 baseline 仅小幅改善，落后外部强 baseline |
| BMS | Isolation Forest FAR=0.172% | 未完成 | 暂无完整 C3 对照结论 |

论文中建议将结果概括为：

> 完整 C3 在 MSL 上相对于外部 baseline 取得明显排序收益；SMAP 的干净 seed=3407 中则低于内部 MTAD-GAT baseline，不能声称改进；Brand3 正在按统一 DyAD 协议重跑；BMS 不再纳入本轮运行。

本报告不纳入任务 103 的机制消融结果，以保持“外部对比实验”和“C3 消融实验”的实验角色分离。
