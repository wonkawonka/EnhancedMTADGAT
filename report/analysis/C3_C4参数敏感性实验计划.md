# C3/C4 参数敏感性实验计划

更新时间：2026-08-28

## 1. 实验定位

本计划用于回答“关键超参数变化时模型是否稳定”，与 C3/C4 的机制消融实验分开编号、分开报告。敏感性实验采用 One-Factor-at-a-Time（OFAT）：每次只改变一个参数，其余设置保持冻结值。敏感性结果不替换正式四张主表中的结果，也不根据测试集最高点重新定义正式模型。

任务 07 的外部模型不纳入本计划。

## 2. 统一协议

- seed：第一阶段统一 `3407`；第二阶段只对正式值及其左右邻近点补 `3408/3409`。
- 内部训练：最大 30 epoch、关闭早停、选择 `best_validation` checkpoint。
- 数据边界、归一化、窗口、阈值和评分聚合均与正式实验一致。
- C3 的 MSL/SMAP 使用 `all→0`；Brand3 使用 DyAD `paper_protocol`。
- C4 只在 Brand3 做参数敏感性；BMS 不参与调参，只在冻结配置稳定后做 FAR 迁移验证。

冻结参照：

- **C3**：Prototype-Query，`regime_num_prototypes=6`、`regime_emb_dim=8`、`regime_film_scale=0.10`、`regime_aux_lambda=0.05`、`regime_temperature=0.5`。
- **C4 v2**：零中心状态条件物理图门控 + 主干 GRU `h_end` 响应头；`physical_graph_gate_scale=0.75`、`physical_graph_bias_weight=1.0`、`physical_consistency_aux_weight=0.05`、`regime_aux_lambda=1.0`、`physical_consistency_score_max_weight=0.05`。

其中 C4 敏感性中的响应辅助强度 λc 定义为训练总损失中的 `regime_aux_lambda` 乘子；`physical_consistency_aux_weight=0.05` 保持不变。因此正式点 λc=1.0，实际响应辅助项仍为 `1.0×0.05`。

## 3. C3 参数敏感性

### 3.1 参数与取值

只测试最直观的三个核心结构/强度参数，不再单独扫描 query dimension、head 数、temperature 或辅助损失权重。

| 参数 | 含义 | 建议取值 | 正式值 |
|---|---|---|---:|
| 原型数量 `regime_num_prototypes`（Np） | 工况原型数量 | 2、4、6、8、10 | 6 |
| 状态嵌入维度 `regime_emb_dim`（dz） | 工况状态表示维度 | 4、8、16、32 | 8 |
| FiLM 强度 `regime_film_scale`（λf） | 状态对主干特征的调制幅度 | 0.02、0.05、0.10、0.20、0.30 | 0.10 |

### 3.2 数据集和阶段

- **第一阶段屏幕**：Brand3 fold 0 + MSL，seed=3407。每个参数轴只改变该参数，其余使用冻结值。
- **第二阶段确认**：每个轴保留正式值及左右邻近点，补 seed=3408、3409；Brand3 在五折上报告均值±SD，MSL 报告三 seed 结果。
- Brand3 代表电池场景，MSL 代表公开 NASA 多变量异常检测场景；不再把所有数据集都纳入敏感性扫描。

单 seed 配置数为 `5+4+5=14`（冻结参照复用正式结果），Brand3+MSL 共 **28 个训练/评估任务**。

### 3.3 指标和图

- Brand3：车辆级 AP 为主，AUROC 为辅；P/R/F1 作为次指标。
- MSL：AP、AUROC。
- 绘制三张折线图：`Np–AP`、`dz–AP`、`λf–AP`；必要时附 AUROC 曲线。
- 正文重点讨论性能波动和稳定区间，不要求正式值必须是绝对最高点。

## 4. C4 参数敏感性

C4 只在 Brand3 进行，避免在只有正常样本的 BMS 上用误报结果调参。C4 的物理图与响应分支保持当前 v2 结构，不扫描普通 GRU hidden size 等通用容量参数。

### 4.1 参数与取值

| 参数 | 含义 | 执行取值 | 正式值 |
|---|---|---|---:|
| 物理图门控强度 λg = `physical_graph_gate_scale` | 动态物理关系对 Feature-GAT 的调制幅度 | 0、0.10、0.25、0.50、0.75、1.00 | 0.75 |
| 响应辅助强度 λc = `regime_aux_lambda` | 响应一致性项进入总训练损失的乘子 | 0、0.25、0.50、1.00、2.00 | 1.00 |
| 响应评分融合上限 ωmax = `physical_consistency_score_max_weight` | 物理响应证据在最终异常分数中的最大占比 | 0、0.02、0.05、0.10、0.20 | 0.05 |

说明：原先针对旧 C4（`physical_graph_bias_weight=0.5`、响应辅助乘子 1.0、score=0.35）的范围不再直接使用；本表已按当前冻结 C4 v2 的中心值修订。C4 敏感性改变 λc 时，`physical_consistency_aux_weight=0.05` 固定；改变 λg 时，`physical_graph_bias_weight=1.0` 和动态关系类型门控结构固定。

### 4.2 数据集和阶段

1. **fold 0 屏幕**：三个参数轴分别运行，冻结参照复用 118 的对应输出。
2. **五折确认**：每个轴仅对正式值及左右邻近点做五折确认；正式 C4 主模型继续固定为 gate=0.75、λc=1.0、ωmax=0.05。
3. **BMS 迁移**：只迁移冻结 C4 和预注册代表点，报告 FAR、每万窗口误报和 cluster 波动，不以 BMS 结果选择参数。

单 seed 配置数为 `6+5+5=16`，Brand3 共 **16 个训练/评估任务**。

## 5. 评价、记录和图表

| 项目 | C3 | C4 |
|---|---|---|
| 主指标 | Brand3 AP；MSL AP/AUROC | Brand3 车辆级 AP/AUROC |
| 次指标 | Brand3 AUROC、P/R/F1 | 车辆级 P/R/F1、校准集 AUROC |
| BMS 迁移指标 | FAR、误报/万窗口 | FAR、误报/万窗口 |
| 统计方式 | seed=3407 曲线；邻近点补三 seed | fold 0 曲线；邻近点五折均值±SD |
| 额外诊断 | 原型路由熵、FiLM 调制幅度 | gate 调制均值/绝对值、响应辅助损失、融合分数贡献 |

每个点保存完整配置、训练曲线、验证最优 epoch、checkpoint、`metrics.json`、运行时间和必要的路由/门控诊断。曲线必须展示全部预登记点，不只展示最高点。

## 6. 防止与消融混淆

1. C3 的 No-Aux、Shuffled-State 与 C4 的 Graph-only、Response-only 属于机制消融，不放入参数敏感性曲线。
2. 参数轴和取值在运行前固定；不得运行后扩大或缩小范围以挑选有利结果。
3. 测试 AP/AUROC 只用于绘制已登记曲线和最终描述，不用于选择正式配置；推荐区间使用验证损失或校准集指标确定。
4. 若不同点的差异落在五折/多 seed 波动范围内，报告“稳定区间”，不声称显著优于其他点。

## 7. 运行规模与时间预算

单 seed：

- C3：14 个配置 × Brand3、MSL = **28 个任务**。
- C4：16 个配置 × Brand3 = **16 个任务**。
- 合计：**44 个训练/评估任务**。

粗略单次耗时按现有模型规模估计：C3 Brand3 10–20 分钟，C3 MSL 20–40 分钟，C4 Brand3 15–30 分钟。完全串行约 **11–22 小时**；三 seed 全扫约 **33–66 GPU 小时**。

按推荐的“两阶段”方案，第一阶段 44 个 seed=3407 点约 11–22 小时；第二阶段只补正式值及左右邻近点，预计再增加约 9–18 小时，合计约 **20–40 GPU 小时**。单张 T4 连续运行约 1–2 天，考虑 Kaggle 排队、数据预处理和失败重试，建议按 **2–3 天墙钟时间** 预算。若把全部 44 个点完整扩展到三 seed，则按 33–66 GPU 小时的上限估算。

建议执行顺序：

1. 第一阶段只跑 seed=3407 全部 44 个点，预计半天到一天（按 Kaggle 并行/排队情况）。
2. 查看曲线后，每个参数只对正式值及左右邻近点补 seed=3408、3409，避免完整三 seed 扫描。
3. 若有两张 T4 并行，墙钟时间大致减半；本地 GPU 与 Kaggle 分开排队，禁止同一张 GPU 并发。

## 8. 论文组织

C3 增加一张包含三条曲线的敏感性图和一张汇总表，正文说明原型数量、状态嵌入维度和 FiLM 强度在一定范围内的稳定性。C4 增加一张包含三条曲线的敏感性图和一张汇总表，正文说明适度物理门控、响应辅助约束和响应评分融合的有效区间。

这些图表作为补充分析，不混入 C3/C4 的正式对比表和机制消融表。
