# C4 Brand3 fold 0 本地筛查（2026-08-26）

## 结论

当前 C4 v1 的“固定物理边 + 手工动态门控”不能进入正式三种子五折。图分支在 Brand3 fold 0 明显降低 AP 和 AUROC；完整模型也没有显示两条路径的互补性。响应一致性分支使 AP 小幅上升，但 AUROC 下降，说明它仅提供部分头部排序证据，尚未改善整体车辆排序。

本次为开发性单折筛查，测试结果不用于论文主表、超参数选择或正式显著性结论。

## 共同协议

- 数据：Brand3，fold 0，seed 3407；
- 切分：`strict_normal_validation`；
- 归一化：仅训练正常车辆拟合的逐通道 MinMax；
- 窗口：片段固定 128 点，`lookback=127`，每片段 1 个合法窗口；
- 训练：最多 10 epoch，patience 3；
- 评分：response 通道、固定车辆 Top-5% 片段、正常验证 P99 阈值。

训练/验证/测试窗口数分别为 16,731 / 4,712 / 8,155；对应车辆数为 54 / 18 / 28。

## 结果

| 实验臂 | Vehicle AP | Vehicle AUROC | 相对 baseline 的 AP |
| --- | ---: | ---: | ---: |
| MTAD-GAT baseline | 0.5809 | 0.7485 | — |
| Graph-only v1 | 0.5168 | 0.6959 | -0.0641 |
| Response-only v1 | 0.5997 | 0.7310 | +0.0188 |

四个实验的输出位于 `runs/internal/106_c4_brand3_fold0_local_screen/output/`。

## 为什么图分支失败

v1 的基础物理边先固定加 1，再以 `lambda_g=0.5` 加到 Feature-GAT logits；电流能量、压差、温差和 SOC 变化只是在此基础上额外提高对应边。

对正常验证窗口实际测得：物理边的总先验均值为 1.198，乘以 `lambda_g` 后的 logit 位移均值为 +0.599，范围为 +0.500 至 +0.996。也就是说，大部分影响来自所有物理边持续存在的固定正偏置，而不是状态相关的动态变化；这已足以压缩 GAT 数据驱动纠错的空间。

## DyAD 论文复核协议与严格主协议

| 项目 | DyAD / `paper_protocol` | 当前严格协议 / 任务 07 |
| --- | --- | --- |
| 车辆切分 | 正常车第 i 折作测试正常；其余正常车训练。故障车第 i 折进入带标签校准，其余故障车测试。 | 正常车一折测试、一折独立正常验证、其余训练；所有故障车只进入测试。 |
| 阈值与 Top-p | 使用带标签校准折；公开 notebook 在 5%–95% 搜索鲁棒 Top-p。 | 只用正常验证分数冻结 P99 阈值；Top-5% 预先固定。 |
| 归一化 | 前 200 条训练片段按通道估计均值和 `max(std, 0.1 × range)`。 | 所有训练正常片段拟合逐通道 MinMax。 |
| 窗口 | Brand3 片段固定 128 点，DyAD 将完整片段作为样本。 | C3/C4 `lookback=127`，同样每片段仅一个合法窗口。 |

因此，旧 C3 任务 101 的 `paper_protocol + paper_channel` 结果不能直接同任务 07 的 `strict_normal_validation + MinMax` 外部模型并列。此前“中央 1 窗口造成 Brand3 漏检”的解释不成立：在当前固定 128 点片段上没有额外窗口可采。

## C4 v2 建议

不要继续添加更多手工边或 GAT—物理图一致性损失。将图分支替换为“零中心、状态条件的关系类型门控”：

1. 保留四类可解释边掩码：负载—热、负载—电压、SOC—电压、极值平衡；
2. 从物理状态描述量生成四个有界 gate，而不是固定所有物理边为正；gate 初始化为 0，使模型初始严格等于 MTAD-GAT；
3. gate 仅调制既定关系类型，不能生成任意全连接图；
4. 响应分支改接主干 GRU 状态，使响应辅助损失能反向塑形主干表征，同时保留独立响应残差评分；
5. 先复跑同一 fold 0 四臂筛查。只有 Graph-only 和 Full 均超过 baseline，才恢复 105 三种子五折。
